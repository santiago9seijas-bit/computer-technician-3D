### 💻 Método de Descarga e Instalación

1. **Descarga:**
   - Haz clic en el enlace de descarga directa anterior, o entra a la página de [GitHub Releases](https://github.com/santiago9seijas-bit/computer-technician-3D/releases/tag/v0.0.0-alpha) y descarga `ComputerTechnician3D-Windows-v0.0.0-alpha.zip`.
2. **Extracción:**
   - Haz clic derecho sobre el archivo `.zip` descargado.
   - Selecciona **"Extraer todo..."** y elige una carpeta de tu preferencia (por ejemplo, `C:\Juegos\ComputerTechnician3D`).
3. **Ejecución:**
   - Entra en la carpeta extraída.
   - Haz doble clic en `ComputerTechnician3D.exe` para iniciar el juego.
   - *Nota importante:* El archivo `ComputerTechnician3D.pck` debe permanecer siempre en la misma carpeta que `ComputerTechnician3D.exe`.

### ⚙️ Requisitos del Sistema (Windows)
- **Sistema Operativo:** Windows 10 o Windows 11 (64 bits).
- **Procesador:** CPU Dual Core o superior con soporte x86_64.
- **Gráficos:** Tarjeta de video compatible con DirectX 11 / 12 o Vulkan.
- **RAM:** 4 GB mínimo recomendado.
