### 💻 Método de Descarga e Instalación

#### Opción A: Vía Terminal (Recomendado)
```bash
# 1. Descargar el archivo comprimido
wget https://github.com/santiago9seijas-bit/computer-technician-3D/releases/download/v0.0.0-alpha/ComputerTechnician3D-Linux-v0.0.0-alpha.zip

# 2. Descomprimir en una carpeta
unzip ComputerTechnician3D-Linux-v0.0.0-alpha.zip -d ComputerTechnician3D-Linux
cd ComputerTechnician3D-Linux

# 3. Otorgar permisos de ejecución al binario
chmod +x ComputerTechnician3D.x86_64

# 4. Iniciar el juego
./ComputerTechnician3D.x86_64
```

#### Opción B: Vía Interfaz Gráfica
1. Descarga el archivo desde el enlace directo o desde [GitHub Releases](https://github.com/santiago9seijas-bit/computer-technician-3D/releases/tag/v0.0.0-alpha).
2. Abre tu explorador de archivos, haz clic derecho sobre el zip y selecciona **"Extraer aquí"**.
3. En la carpeta extraída, haz clic derecho sobre `ComputerTechnician3D.x86_64`, ve a **Propiedades** > **Permisos**, y marca la casilla **"Permitir ejecutar el archivo como un programa"**.
4. Haz doble clic para jugar.
